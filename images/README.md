# ヘッダー背景画像について

このディレクトリに `header-bg.jpg` という名前で背景画像を配置してください。

## 推奨サイズ

- 幅: 1920px以上
- 高さ: 300-400px程度
- 形式: JPG, PNG, WebP

## 画像がない場合

背景画像がない場合は、グラデーション背景が表示されます。

## 画像のアップロード方法

1. WordPressのメディアライブラリから画像をアップロード
2. 画像のURLを取得
3. `style.css`の `.header-background` セクションで `background-image` のURLを更新

または、このディレクトリに直接 `header-bg.jpg` を配置してください。
